# Aurcus Companion branding assets

Assets generated from the branding concept sheet and included as visual resources:
- `aurcus_app_icon.png` — square app icon source crop
- `aurcus_horizontal_logo.png` — horizontal brand logo crop
- `aurcus_floating_icon.png` — minimized floating bubble emblem; used in FloatingOverlayService header
- `aurcus_floating_header.png` — floating header design reference
- `aurcus_feature_*.png` — feature icon crops for future UI integration
- `aurcus_branding_reference.png` — full original concept sheet

Android resources are in `app/src/main/res/drawable-nodpi/`; launcher icon is in `mipmap-xxxhdpi/ic_launcher.png`.
These are generated concept artwork crops, not individually hand-redrawn vector assets. Verify visual fit on device and replace with clean transparent exports if needed.
